D&A Italy.Mau — primera versión funcional local
1. Sube TODO el contenido de esta carpeta a la raíz de un repositorio de GitHub Pages.
2. Activa GitHub Pages desde Settings > Pages (rama principal, carpeta /root).
3. Abre el enlace publicado en Chrome Android y elige Instalar app / Añadir a pantalla de inicio.
4. Abre la app una vez con Internet para que se almacenen los archivos y después podrá abrir sin conexión.
5. Usa Copias > Exportar copia de seguridad regularmente. Guarda el JSON fuera del teléfono.
6. Para restaurar, abre Copias > Importar copia de seguridad.
Avisos:
- Los datos viven en el almacenamiento local de este navegador/dispositivo.
- Esta versión inicial no sincroniza varios dispositivos.
- No borres almacenamiento/datos de Chrome sin exportar una copia.
- El control financiero es una base inicial: revisa los importes antes de usarla como contabilidad oficial.

ACTUALIZACIÓN v2: reemplaza los archivos del proyecto con esta versión. Se añade doble almacenamiento local (localStorage + IndexedDB) y se actualiza la caché del Service Worker. Si los datos ya se borraron del navegador y no existe respaldo, no es posible reconstruirlos automáticamente.

NOVEDAD v4 — PRODUCCIÓN POR LOTES
- Guarda recetas reutilizables con producto terminado, rendimiento base e ingredientes del inventario.
- Al confirmar un lote, la app valida las existencias y descuenta automáticamente los ingredientes.
- Añade las unidades buenas fabricadas al inventario del producto terminado.
- Registra unidades defectuosas/merma sin añadirlas al inventario vendible.
- Calcula costo total de ingredientes y costo por unidad buena; crea número de lote y conserva historial con detalle.
- Permite cambiar el multiplicador de receta y ajustar las unidades buenas obtenidas antes de confirmar.
- La producción por lotes es adicional al flujo manual anterior.

Antes de actualizar, exporta una copia de seguridad desde la pestaña Copias. Reemplaza todos los archivos en GitHub por los de esta carpeta. La app mantiene la misma clave local de datos, pero conserva siempre una copia de seguridad por precaución.


ACTUALIZACIÓN v5 — IPV RESTAURADO
Esta versión conserva el módulo de recetas y lotes de producción de v4 y vuelve a incluir el cierre diario de IPV con confirmación, historial de cierres, corrección de datos históricos y detalle de inventario. Al abrir un cierre con el botón “Ver”, también muestra los movimientos de productos y ventas guardados para esa fecha.
Antes de reemplazar los archivos, exporta una copia de seguridad desde Copias. Se mantiene la misma clave de almacenamiento local. El service worker usa una caché nueva para actualizar la interfaz.
